## 5. PUBLIC DEBTOR API MODEL & SECURITY

- Endpoint: `GET /api/v1/public/saoke/debtors?month=YYYY-MM` (Unauthenticated public access).
- Filter: Displays ONLY debtors where `remainingAmount > 0`.
- Supports: `FIXED` members and `VISITOR` members.
- Allow-List DTO (`PublicDebtorDTO`): `memberName`, `memberType`, `month`, `totalFeeRequired`, `paidAmount`, `remainingAmount`, `status`, `paymentReference`.
- **Sanitization**: `memberId`, `phone`, `email`, `address`, `password`, `passwordHash`, `token`, and internal keys are strictly excluded.
